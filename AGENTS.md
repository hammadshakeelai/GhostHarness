# Project Rules & Preferences

## GitHub Repository Creation & Management
Whenever creating, initializing, or publishing a new GitHub repository:
1. **Fully Configure the GitHub "About" Section Immediately:**
   - **Description**: Always set a concise, high-impact, professional description summarizing the project's purpose and technical architecture (`gh repo edit --description "..."`).
   - **Homepage URL / Demo Link**: Always configure the homepage link if a demo website, GitHub Pages site, or documentation portal is deployed (`gh repo edit --homepage "..."`).
   - **Topics & Tags**: Always add 10–15 relevant repository topic tags covering framework, tools, models, hardware optimization, and domain keywords (`gh repo edit --add-topic "..."`).
2. **Never leave the repository's About section, tags, or description blank.**
